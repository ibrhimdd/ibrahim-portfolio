# Ibrahim Elkhooly — Creative Developer Portfolio

A bilingual creative developer portfolio with Arabic RTL and English LTR layouts.

## Built with
- React + Vite
- Tailwind CSS v4
- GSAP + ScrollTrigger
- Lucide React

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Customize
- Edit content and language strings in `src/App.jsx`.
- Edit colors, typography, animations' visual styling, and responsive layouts in `src/index.css`.
- Replace the placeholder email address and social links before publishing.
- Project cards are currently visual placeholders; add real URLs, screenshots, and case studies when ready.
